# GYRO · 苍穹突击

使用现有 F-22 平滑金属模型的第三人称 3D 空战游戏，新增 ESP32-C3 + MPU6050 无线体感模式。

## 启动

Windows 双击 `start-game.cmd` 或桌面「苍穹突击」快捷方式，保持服务窗口开启。Ctrl+C 停止服务。

其他环境在本目录运行：

```text
python gyro_bridge.py --open
```

需要 Python 3.10+，不需要安装第三方 Python 包；浏览器需要 WebGL 2。端口默认 8765，占用时自动寻找后续空闲端口，终端显示实际地址。

Three.js 0.180.0 和模型随项目保存，离线可玩。**体感模式必须使用 `gyro_bridge.py` 启动**；普通静态服务器可运行键盘模式，但不提供无线接收功能。

## 操作与规则

- WASD / 方向键：左右移动、升降；触屏提供摇杆。
- 右上角「体感控制」：选择 MPU6050 模式，连接并设置中位后倾斜移动。
- 空格 / FIRE：按住持续开火；F 或底部按钮切换自动 / 手动开火。
- P / Esc：暂停、继续；切换窗口、打开体感设置时自动暂停。
- 金币 +25 分；击毁敌机 +200 分；飞行每秒 +8 分。
- 5 格生命，受伤后短暂无敌；橙色岩石不可击毁，必须绕行。
- 红色敌机需要多次命中，并会向玩家射击；击毁后掉落金币。
- 每 25 秒进入下一战区，提高飞行速度、敌机生命与攻击频率。
- 最佳分数及体感灵敏度保存在当前浏览器本地。每次打开默认键盘模式，体感中位不跨会话保存。

## 体感使用

接线、固件和校准详见 [固件说明](../firmware/README.md)。连接开发板 Wi-Fi 后，在游戏中使用默认地址 `192.168.4.1`。默认网络密码为 `GyroPlay32`。

断线、传感器异常或数据超时会自动暂停，重新连接后设置中位，再手动继续。满速倾角越小越灵敏；手抖时可增大死区。可选交换轴向与左右 / 上下反向。

### 常见情况

- **等待本地游戏服务**：关闭旧静态服务，通过桌面快捷方式重新打开游戏。
- **等待开发板 / 信号中断**：确认电脑已连上 GYRO-C3 Wi-Fi、开发板有电；关闭另一个正在连接控制器的游戏窗口，再重试。
- **请检查 MPU6050 接线**：无线已接通，但传感器未就绪。断电检查 3V3 / GND / SDA4 / SCL5。
- **静置校准中**：不要晃动控制器，等待约 2–4 秒或更久。重新校准后要重新设置中位。
- **方向不符合预期**：交换轴向或反向，然后设置中位。
- **连接 AP 后没有互联网**：这是开发板直连网络；游戏的模型与依赖均可离线运行。
- **系统防火墙拦截 Python**：检查安全软件是否阻止 Python 到开发板的 UDP 4210 流量，无需关闭整个防火墙。

本游戏不含在线排行榜。模型位于 `dist/assets/airplane-f22.glb`，原始素材位于 `../assets/models/`。Three.js 许可证见 `dist/vendor/LICENSE.txt`。
