# GYRO · 苍穹突击

F-22 平滑金属飞机的第三人称 3D 空战游戏，支持键盘、触屏和 ESP32-C3 + MPU6050 蓝牙体感。

## 启动

双击 `start-game.cmd` 或桌面「苍穹突击」快捷方式。启动器优先使用支持 Web Bluetooth 的 Edge / Chrome，保持服务窗口开启，Ctrl+C 停止。

```text
python server.py --open
```

需要 Python 3.10+，不需第三方 Python 包；浏览器需要 WebGL 2。`server.py` 只提供本机静态文件，默认端口 8765，被占用时寻找后续空闲端口。模型、Three.js 和游戏均保存于本地。

## 操作与规则

- WASD / 方向键：移动和升降；触屏提供摇杆。
- 「蓝牙体感」：选择 MPU6050 蓝牙体感，连接设备并设置中位后倾斜移动。
- 空格 / FIRE：按住开火；F 或底部按钮切换自动 / 手动开火。
- P / Esc：暂停、继续；切换窗口或打开体感设置时暂停。
- 金币 +25 分；击毁敌机 +200 分；飞行每秒 +8 分。
- 5 格生命，受伤后短暂无敌；橙色岩石不可击毁。
- 红色敌机需要多次命中，会向玩家射击，击毁后掉落金币。
- 每 25 秒提升战区难度。最佳分数和灵敏度在浏览器本地保存。

## 蓝牙体感

接线和固件见 [固件说明](../firmware/README.md)。重新烧录蓝牙版后，开启电脑蓝牙，在游戏里点击「连接蓝牙」，选择 `GYRO-C3-BLE-xxxx`。静置校准后，以舒适握姿设置中位。

每次打开默认键盘模式，中位不跨连接保存。数据停顿 150 ms 时临时冻结飞行，短时恢复后自动继续并保留中位；持续 750 ms 才显示暂停，恢复后手动继续。真正蓝牙断开、传感器异常或重新校准后才需要重新设置中位。可调整满速倾角、死区、交换轴向和方向反转。

### 常见情况

- **请使用支持蓝牙的 Chrome / Edge**：换用 Chrome / Edge，通过本地快捷方式打开，并开启电脑蓝牙。
- **设备列表没有控制器**：确认已烧录新固件、开发板有电，且未被另一个电脑或游戏窗口连接。
- **蓝牙已连接 · 请检查 MPU6050 接线**：断电检查 VCC→3V3、GND→GND、SDA→4、SCL→5。
- **静置校准中**：保持静止，等待约 2–4 秒或更久；之后设置中位。
- **蓝牙已连接 · 等待姿态数据**：重新连接，确认通知已开启，查看固件串口日志。
- **方向相反**：调整交换轴向 / 方向反转，再设置中位。

测量值显示命令往返、最近一秒通知接收频率和本机数据年龄。它们不代表动作到画面的总延迟。

测试可在仓库根目录运行 `node game/test-ble.mjs` 与 `node game/test-game.mjs`。软件测试不能替代真实传感器和蓝牙硬件联调。
