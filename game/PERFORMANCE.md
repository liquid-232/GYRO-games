# 苍穹突击性能排查记录

日期：2026-10-16。排查基线：d2a8c06。用户反馈：键盘与 USB 游玩均会出现卡顿、慢动作。

## 确定的计时错误

旧动画循环使用 Math.min((now-last)/1000,.033)，把每帧游戏时间限制为 33 ms。低于约 30 FPS 时，超出的真实时间被直接丢弃；20 FPS 下，现实 10 秒只推进游戏 6.6 秒。飞机、敌机、子弹、地图、技能冷却都会同时变慢，符合用户描述。

现改为按真实帧间隔推进，再拆为不超过 1/60 秒的碰撞子步。输入每个画面帧只读取一次，粒子 GPU 数据每帧只提交一次；单次超过 250 ms 的停顿限制追赶量。暂停、后台与体感过期仍冻结游戏，不补跑中断期间的战斗。

## 独立浏览器复现

本机 Edge 无头浏览器实际使用 NVIDIA GeForce RTX 4060 Laptop GPU / ANGLE D3D11；CSS 视口 1920 × 1080，初始 DPR 1.5。旧版测试加载 Git 基线源码，两个版本使用独立浏览器，不操作用户的浏览器或真实控制器。

对 requestAnimationFrame 人为增加 40 ms 调度延迟，得到约 20 FPS，每张地图采样约 6 秒。此对照用于验证低帧率下的计时，不能视作硬件帧率提升的测量。新版在该持续低帧率下会按设计降低内部渲染比例。

| 地图 | 旧版 FPS | 新版 FPS | 旧版游戏时间/现实时间 | 新版游戏时间/现实时间 |
| --- | ---: | ---: | ---: | ---: |
| 轨道禁区 | 21.2 | 21.2 | 69.8% | 99.5% |
| 群岛战区 | 19.7 | 21.2 | 65.0% | 100.3% |

小于 1% 的计时偏差来自读取状态与帧回调边界。纯逻辑测试在 10、15、20、24、30、60、120、165 FPS 下，现实 10 秒均推进游戏 10 秒。

## 渲染开销与改动

- 旧版逐粒创建 Mesh、Material 并在过期时销毁，产生大量绘制调用和临时对象。改为上限 384 个的预分配实例池，战斗碎粒与导弹尾迹共用一次实例化绘制。
- 爆炸资源与多种材质原本在首次出现时准备。启动阶段准备常见战斗材质、两张地图与海面裁剪变体，保留少量隐藏材质引用，避免对应程序在特效结束后完全回收、下次再次编译。纹理初始化也前移。
- 群岛海面反射由每帧绘制改为最多 30 Hz，机体阴影在主画面更新，仪表最多 10 Hz。锁定框与主画面继续每帧更新。
- 持续低帧率时按窗口缓慢降低分辨率；稳定恢复 8 秒以上再逐步提高。暂停、后台、姿态过期及超过 250 ms 的单次长帧不触发降质。

常规短时采样未人为延迟回调，两个版本均保持 DPR 1.5。压力场景每 650 ms 触发一次敌机爆炸和 35 枚碎粒，每项采样约 6 秒；航线与粒子包含随机性，绘制调用仅表示本次样本。

| 压力场景 | 旧版绘制调用 P95 | 新版绘制调用 P95 | 旧版 render CPU 耗时 P95 | 新版 render CPU 耗时 P95 |
| --- | ---: | ---: | ---: | ---: |
| 轨道禁区 | 236 | 190 | 1.5 ms | 0.8 ms |
| 群岛战区 | 349 | 265 | 4.7 ms | 1.6 ms |

render CPU 耗时为当帧 renderer.render 调用时间之和，不等同于 GPU 总耗时或完整输入延迟。

旧版群岛样本记录到约 360 ms 长任务，受控低帧率复现还记录到约 344 ms 长任务；修复后本次样本均未记录到超过 50 ms 的长任务。代码检查与预热后对照支持首次材质/着色器准备是诱因，但未追踪到某一个 GPU 驱动调用，不能保证所有外部负载导致的长帧都消失。

原始本机采样保存于 game/.runtime/performance-before.json、performance-after.json、performance-before-paced.json、performance-after-paced.json；该目录已忽略，不上传机器相关运行文件。已检查修复后的实际渲染截图，浏览器页面错误及控制台错误为空。

## 回归检查

在仓库根目录运行：

```text
node game/test-performance.mjs
node game/test-game.mjs
node game/test-ble.mjs
node game/test-usb.mjs
node game/test-control-frame.mjs
node game/test-receive-latency.mjs
node game/test-enemy-model.mjs
```

检查覆盖时间一致性、航程和技能冷却、分步碰撞、暂停/体感过期冻结、冷弹射/追踪/重新锁定、粒子上限/复用/释放、自适应分辨率滞回、蓝牙与 USB 协议及操控轴。以上均已通过。

本次不涉及固件更新。首次进入会有战场准备时间；持续低帧率时画面清晰度会暂时降低。长期手持实机游玩与其他应用同时运行时的系统负载尚需继续观察。
