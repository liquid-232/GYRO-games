# GYRO · 苍穹突击

使用定制 F-22 平滑金属模型的 3D 空战小游戏，支持键盘、触屏与 **ESP32-C3 + MPU6050 无线体感操控**。躲避岩石、拾取金币、击毁敌机，可切换自动 / 手动开火。

## 开始游戏

Windows 双击 `game/start-game.cmd`，或使用已创建的桌面「苍穹突击」快捷方式。需要 Python 3.10+ 和支持 WebGL 2 的浏览器；脚本优先使用本机已有的 Python 运行时。保持服务窗口运行。

```powershell
python game/gyro_bridge.py --open
```

游戏和 Three.js 已保存在本地，游玩无需联网或 CDN。GitHub 保存源码和素材，不是无线控制的中转服务器。

## 无线体感：首次使用

1. 断电接线：MPU6050 `VCC → 3V3`、`GND → GND`、`SDA → GPIO4`、`SCL → GPIO5`。
2. 使用 `tools/esp32.ps1 flash` 烧录本项目固件，详见 [固件说明](firmware/README.md)。本机 COM29 已完成烧录。
3. 给开发板供电，电脑连接 `GYRO-C3-xxxx` Wi-Fi，出厂密码 **`GyroPlay32`**。控制器地址为 **`192.168.4.1`**。
4. 打开游戏右上角「体感控制」，选择「MPU6050 体感」，点击「连接」。首次启动保持传感器静止约 2–4 秒。
5. 握住控制器，板面尽量朝上，保持舒适姿态静止，点击「以当前姿态为中位」。关闭面板，开始出击。
6. 倾斜控制器控制左右、升降；空格开火，F 切换自动 / 手动开火。方向不符合握持习惯时，可交换轴向、反转方向。

开发板只需供电即可无线游玩，USB 不传输控制数据。默认直连 Wi-Fi 没有互联网；游戏可以离线运行。一次连接一台电脑。

## 控制设计

- MPU6050 目标采样率 200 Hz，姿态数据目标发送率 100 Hz，400 kHz I²C。
- 静止陀螺仪零偏校准、四元数六轴融合、加速度异常降权，控制横滚和俯仰。
- UDP 只发送最新数据，校验会话、序号、数值范围，丢弃重复 / 乱序和确认过期的数据。
- 可调整满速倾角、中心死区与方向；12 ms 时间常数的输入平滑。
- 数据超过 150 ms 未更新、传感器异常或本地连接中断时自动暂停。恢复后重新设置中位，并手动继续。
- 游戏显示实际接收频率、通信往返时间和数据年龄。往返时间不等于动作到画面的总延迟。

这些频率是配置目标。真实延迟、噪声和姿态精度受接线、传感器、无线环境、电脑和显示器影响；没有将目标值标作实测值。当前已完成固件编译、烧录及启动日志读取，**MPU6050 尚未接入，真实体感精度和完整无线游玩链路仍待硬件联调**。
