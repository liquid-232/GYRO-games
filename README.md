# GYRO · 体感游戏合集

使用 **ESP32-C3 + MPU6050**，将手中的倾斜动作变成游戏操作。仓库包含「重力滚球」和「苍穹突击」两款独立 3D 游戏，支持蓝牙、Type-C USB 有线、键盘及触屏操控。

## 重力滚球 · GRAVITY MAZE

**一点倾斜，一场探索。** 轻轻倾斜控制器，让金属小球穿过曲折通道、绕开陷阱、慢慢越过窄桥；收齐三颗星星后抵达终点，挑战更快、更稳的通关记录。

![重力滚球：儿童房木桌上的立体迷宫球，右上角可退出全屏](assets/models/maze-fullscreen-preview.jpg)

### 两种迷宫，六个关卡

- **立体迷宫球**：透明球壳、彩色曲面轨道和金属钢珠组成的玩具迷宫。随着滚球前进，整个玩具转动展示路线；三关逐步加入起伏坡道、窄桥与更大的惯性。
- **经典平面迷宫**：在俯视迷宫中寻找路线，控制速度绕过陷阱，适合熟悉体感操作。
- **星星与检查点**：每关收集三颗星星，再进入终点。球面模式掉落后返回最近星星检查点，平面模式返回起点；已收集星星保留。
- **儿童房场景**：迷宫球摆放在木桌上，周围有积木、小车和蜡笔，桌后是窗户、书架与家具，配合窗光和材质细节营造玩具质感。

### 启动与操控

Windows 双击 [`gravity-maze/start-maze.cmd`](gravity-maze/start-maze.cmd)，或使用桌面「重力滚球」快捷方式。也可在仓库根目录运行：

```powershell
python gravity-maze/server.py --open
```

需要 **Python 3.10+** 和支持 **WebGL 2** 的 Chrome / Edge。游戏资源随项目提供，可离线运行；`gravity-maze` 文件夹可以单独复制使用。关闭最后一个游戏网页约 2 秒后，本地服务和命令窗口自动关闭。

| 操控方式 | 使用方法 |
| --- | --- |
| 蓝牙体感 | 给 ESP32-C3 供电，在游戏设置连接 `GYRO-C3-BLE-xxxx`，静置校准并设置中位后倾斜控制 |
| USB 有线体感 | 用 Type-C 数据线连接电脑，选择「MPU6050 USB 有线体感」，连接串口并设置中位 |
| 键盘 | 点击「先用键盘试玩」，WASD / 方向键控制，空格刹车，P 暂停 |
| 触屏 | 使用画面中的方向按钮控制 |

控制器就绪后点击开始或继续，会自动进入全屏；点击右上角 **「退出全屏」** 或按 **Esc** 返回窗口继续游玩。浏览器不允许全屏时仍可在窗口中游戏。

### 画质与运行效率

默认提供「自动」画质，也可选择「均衡」或「超清」。采用共享顶点、静态场景变换缓存及分频阴影更新，保留模型面数与光滑度；大厅降低绘制频率，暂停时按需重绘，后台停止绘制。滚球物理使用 120Hz 固定步长，游玩画面最多绘制 60fps，实际表现取决于设备。

> 立体迷宫球采用游戏化的球面约束；外层通道是当前可玩路线，内部附加槽道用于丰富模型展示。

## 苍穹突击 · 3D 空战

使用定制 F-22 平滑金属模型的 3D 空战小游戏，支持键盘、触屏与 **ESP32-C3 + MPU6050 蓝牙 / USB 有线体感操控**。躲避岩石、拾取金币、击毁敌机，可切换自动 / 手动开火。

### 开始空战游戏

Windows 双击 `game/start-game.cmd`，或桌面「苍穹突击」快捷方式。启动器优先打开 Edge / Chrome；体感模式需要支持 Web Bluetooth 的浏览器和电脑蓝牙适配器。Python 3.10+ 仅用于提供本机静态游戏文件，控制数据由浏览器直接通过 BLE 或原生 USB 串口接收。

```powershell
python game/server.py --open
```

启动游戏后，关闭最后一个游戏网页约 2 秒会自动退出服务和命令窗口；刷新页面会继续运行。Three.js、模型和游戏文件均随项目保存，可离线游玩。

## 蓝牙体感：首次使用

1. 断电接线：MPU6050 `VCC → 3V3`、`GND → GND`、`SDA → GPIO4`、`SCL → GPIO5`。
2. 将开发板更新为本项目的蓝牙固件，见 [固件说明](firmware/README.md)。旧固件需要重新烧录。
3. 给开发板供电，开启电脑蓝牙。打开游戏右上角「蓝牙体感」，选择「MPU6050 蓝牙体感」。
4. 点击「连接蓝牙」，在浏览器弹出的设备列表中选择 **`GYRO-C3-BLE-xxxx`**。通过游戏选择设备，无需输入网络地址或密码。
5. 首次上电保持传感器静止约 2–4 秒，显示「姿态就绪」后，保持舒适握姿点击「以当前姿态为中位」。
6. 关闭设置面板，开始出击。倾斜移动；空格开火，F 切换自动 / 手动开火。可调灵敏度、死区、交换轴向和方向反转。

开发板供电后可通过蓝牙无线游玩；也可用 Type-C 数据线接电脑，在体感设置选择「MPU6050 USB 有线体感」，点击「连接 USB」选择 ESP32-C3 串口，静置并设置中位。USB 模式需双模式固件，关闭串口监视器后连接。本机为 COM29。一次游戏连接选择一种传输方式。

## 控制设计

- MPU6050 目标采样率 200 Hz，400 kHz I²C；六轴姿态融合和静止零偏校准。
- NimBLE GATT 姿态通知目标 100 Hz，请求 7.5–15 ms 连接间隔和零外设延迟；实际间隔由电脑蓝牙栈决定。
- 蓝牙设置新增 MPU6050 三维模型与实时 X/Y/Z 三轴，支持立体 / 俯视，偏航为可能漂移的相对角度。
- 单包 20 字节，兼容默认 ATT MTU；角度使用 0.01° 编码分辨率。编码分辨率不等于传感器实测精度。
- 只发送最新样本，限制待发送通知，拒绝错误格式、乱序和已确认过期的数据。
- 150 ms 无新采样时停止操控并暂时冻结飞行，保留中位；持续中断 750 ms 才显示暂停。数据恢复后可继续，真正断开、传感器异常或重新校准才清除中位。
- 实时显示接收频率、命令往返时间和本机接收后的数据年龄。命令往返包括一次 GATT 写入和一次读取，不代表动作到画面的总延迟。

本机已完成真实蓝牙 GATT 收发和传感器静止校准：通知约 100 Hz，6 次命令往返中位数约 55 ms。完整动作到画面的延迟与手持操控精度仍需实际游玩测量。
