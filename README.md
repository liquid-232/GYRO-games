# GYRO · 苍穹突击

使用定制 F-22 平滑金属模型的 3D 空战小游戏，支持键盘、触屏与 **ESP32-C3 + MPU6050 蓝牙体感操控**。躲避岩石、拾取金币、击毁敌机，可切换自动 / 手动开火。

## 开始游戏

Windows 双击 `game/start-game.cmd`，或桌面「苍穹突击」快捷方式。启动器优先打开 Edge / Chrome；体感模式需要支持 Web Bluetooth 的浏览器和电脑蓝牙适配器。Python 3.10+ 仅用于提供本机静态游戏文件，控制数据由浏览器直接通过 BLE 接收。

```powershell
python game/server.py --open
```

启动游戏后，关闭最后一个游戏网页约 4 秒会自动退出服务和命令窗口；刷新页面会继续运行。Three.js、模型和游戏文件均随项目保存，可离线游玩。

## 蓝牙体感：首次使用

1. 断电接线：MPU6050 `VCC → 3V3`、`GND → GND`、`SDA → GPIO4`、`SCL → GPIO5`。
2. 将开发板更新为本项目的蓝牙固件，见 [固件说明](firmware/README.md)。旧固件需要重新烧录。
3. 给开发板供电，开启电脑蓝牙。打开游戏右上角「蓝牙体感」，选择「MPU6050 蓝牙体感」。
4. 点击「连接蓝牙」，在浏览器弹出的设备列表中选择 **`GYRO-C3-BLE-xxxx`**。通过游戏选择设备，无需输入网络地址或密码。
5. 首次上电保持传感器静止约 2–4 秒，显示「姿态就绪」后，保持舒适握姿点击「以当前姿态为中位」。
6. 关闭设置面板，开始出击。倾斜移动；空格开火，F 切换自动 / 手动开火。可调灵敏度、死区、交换轴向和方向反转。

开发板只需供电即可无线游玩，USB 不传输控制数据。一次连接一台电脑。

## 控制设计

- MPU6050 目标采样率 200 Hz，400 kHz I²C；六轴姿态融合和静止零偏校准。
- NimBLE GATT 姿态通知目标 100 Hz，请求 7.5–15 ms 连接间隔和零外设延迟；实际间隔由电脑蓝牙栈决定。
- 蓝牙设置新增 MPU6050 三维模型与实时 X/Y/Z 三轴，支持立体 / 俯视，偏航为可能漂移的相对角度。
- 单包 20 字节，兼容默认 ATT MTU；角度使用 0.01° 编码分辨率。编码分辨率不等于传感器实测精度。
- 只发送最新样本，限制待发送通知，拒绝错误格式、乱序和已确认过期的数据。
- 150 ms 无新采样时停止操控并暂时冻结飞行，保留中位；持续中断 750 ms 才显示暂停。数据恢复后可继续，真正断开、传感器异常或重新校准才清除中位。
- 实时显示接收频率、命令往返时间和本机接收后的数据年龄。命令往返包括一次 GATT 写入和一次读取，不代表动作到画面的总延迟。

本机已完成真实蓝牙 GATT 收发和传感器静止校准：通知约 100 Hz，6 次命令往返中位数约 55 ms。完整动作到画面的延迟与手持操控精度仍需实际游玩测量。
